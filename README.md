# 🪢 Math Tug of War

A two-player math game where teams compete by solving math problems to pull the rope to their side!

## How to Play

1. Two players share one screen (split left/right)
2. Each player gets math questions on their side
3. Type the answer and hit **GO** — correct answers pull the rope toward your side
4. First team to reach the win score wins!

## Features

- 🎵 Synthesized music and sound effects (Web Audio API)
- 🎮 Three difficulty levels (Easy / Medium / Hard)
- 🔥 Streak counter for consecutive correct answers
- 🎨 Animated SVG characters and particle effects
- 📱 Works on phones, tablets, and desktops

## Run Locally

```bash
npm install
npm run dev
```

## Deploy

Push to GitHub and connect to [Netlify](https://netlify.com) — it auto-builds and deploys.

## Tech Stack

- React 18
- Vite
- Web Audio API
- Zero external dependencies
